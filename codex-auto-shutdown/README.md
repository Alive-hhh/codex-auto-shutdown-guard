# Codex 任务完成自动关机

这是一个默认关闭、由你手动开启的 Windows 关机守卫。开启后只等待**下一次经 Codex 确认成功完成的任务**，收到信号后排定关机，并保留可取消倒计时。

## 使用方法

1. 双击 `启动关机守卫.vbs`。如果系统禁用了 VBS，就双击 `启动关机守卫.cmd`。
2. 选择倒计时秒数，点击“开启：等待下一次完成”。
3. 让 Codex 执行任务。窗口可以关闭，它会缩到任务栏通知区域继续运行。
4. Codex 完成并验证任务后会发出成功信号。守卫立即自动解除武装，并进入关机倒计时。
5. 不想关机时，点击“关闭 / 取消关机”，或者双击 `紧急取消关机.cmd`。

窗口标题、主状态栏和托盘提示都会明确显示“已开启”“已关闭”或剩余倒计时。窗口缩到托盘后，再次点击桌面启动快捷方式会把同一个状态窗口叫回前台。

## 任务检测状态栏

窗口顶部单独显示 Codex 当前任务状态：

- 蓝色“N 个任务未完成”：按 Codex 任务 ID 分别登记，显示当前活动任务数和最久运行时间。
- 黄色“N 个任务等待你的操作”：所有剩余任务都在等待输入、批准或外部条件。
- 绿色“所有任务已完成”：活动任务数已经归零，并显示最后完成时间。
- 灰色“未检测到正在运行的任务”：当前没有任务状态信号。

任务状态和关机守卫状态相互独立。即使守卫关闭，任务检测状态仍会更新。多个任务并行时，一个任务完成只会把它自己移出活动集合；只要还有其他任务在运行或等待，界面就不会显示“所有任务已完成”，也不会排定关机。只有活动任务数归零且守卫由你开启时，最后一个成功完成信号才会排定关机。

任务状态文件使用跨进程锁保护，因此多个 Codex 任务几乎同时开始或完成时也不会互相覆盖。

## 安全设计

- 默认关闭，安装和测试不会关机。
- 每次开启只消费一个成功完成信号，触发后自动解除武装。
- 开启之前产生的旧信号会被忽略。
- Codex 被阻塞、等待你的输入、验证失败或只完成一部分时，不应发送成功信号。
- 使用 Windows 的正常关机流程，不加 `/f` 强制关闭参数，降低未保存内容丢失风险。
- 完全退出托盘程序会同时关闭守卫并尝试取消已排定的关机。

## 作用范围

当前接入写在 `D:\codex项目\AGENTS.md`，因此适用于以 `D:\codex项目` 为仓库根目录的新 Codex 任务。其他工作区不会自动发送完成信号。

## 命令行接口

```powershell
# 查看状态
powershell -NoProfile -File .\CodexShutdownGuard.ps1 -Mode status

# 发出完成信号（通常由 Codex 调用）
powershell -NoProfile -File .\Signal-TaskComplete.ps1 -TaskSummary "任务说明"

# 关闭守卫并取消关机
powershell -NoProfile -File .\CodexShutdownGuard.ps1 -Mode cancel
```

实现没有直接使用 Codex `Stop` 钩子，因为 `Stop` 表示回合停止，也可能是等待输入或受阻，并不总是等于任务成功。这里用项目指令让 Codex 只在成功完成和验证后发送信号。
